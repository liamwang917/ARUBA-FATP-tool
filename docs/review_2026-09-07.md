## What is working

- The v12 tool executes successfully on the supplied dataset.
- All 73 DUT serial numbers are unique.
- FR / THD / Phase each produce 73 rows and 80 frequency points.
- Noise produces 73 rows and 800 frequency points.
- Frequency axes are consistent across all 73 DUTs in this dataset.
- Numeric CSV values are written to Excel as numbers, not strings, so Excel statistics work normally.
- `FR_original`, `FR_1_12`, and `Sealing` are empty because the supplied dataset has no corresponding source data; this is not a parser crash.

## Critical semantic issue

All current FR filenames contain `FR_PASS`, but the internal APx FR section reports `Test Result: Fail` for all 73 records. THD and Phase internal results are Pass.

Current v12 writes the filename-derived FR result into the Result column for FR, THD and Phase. This can make the workbook show PASS while an internal APx section reports FAIL.

Recommended change: preserve both meanings independently:

- `Station Result` — filename / FATP station final judgement
- `APx Section Result` — section-level APx judgement

Do not choose one as authoritative until station-limit logic is confirmed.

## P0 recommendations

1. Add separate Station/APx result fields.
2. Add an Import Log / Data QC sheet.
3. Validate every DUT frequency axis and fail loudly on mismatch.
4. Record missing/duplicate files and malformed sections instead of silently skipping.
5. Fix RawData_RD section-boundary detection so prefix-style section names cannot bleed into adjacent sections.

## P1 recommendations

1. Preserve station metadata: operator, station, tester, software version, start/end time, total test time, sensitivity, SNR and other summary fields.
2. Add automatic N / Mean / Max / Min / Range / STDEV statistics by frequency.
3. Convert 14-digit timestamps to real Excel datetimes.
4. Add freeze panes, AutoFilter, useful column widths, number formats and PASS/FAIL conditional formatting.
5. Add explicit status text for empty sheets instead of leaving them visually blank.

## P2 recommendations

1. Add a dashboard after the data model is stable.
2. Add FR Mean/Max/Min and distribution charts.
3. Treat Noise sentinel values such as 0 Hz / -1000 separately from engineering statistics.
4. Add regression tests with small synthetic Online and RawData_RD fixtures.
